# Котошторм Online

Онлайн-игра для трёх участников с общей комнатой и синхронизацией через Socket.IO.

## Запуск локально

```bash
npm install
npm start
```
Откройте http://localhost:3000.

## Публичная ссылка

1. Загрузите содержимое этой папки в новый репозиторий GitHub.
2. На https://render.com выберите New > Web Service и подключите репозиторий (или Deploy Blueprint с render.yaml).
3. Build command: `npm install`; Start command: `npm start`; runtime Node.
4. После публикации Render выдаст публичный адрес вида `https://...onrender.com`.
5. Ведущий создаёт комнату и отправляет ссылку-приглашение двум участникам.

Примечания: бесплатный инстанс Render может засыпать; комнаты хранятся в оперативной памяти и исчезают при перезапуске сервера. Для постоянного хранения потребуется база данных. Игра рассчитана на три одновременно подключённых участника.
